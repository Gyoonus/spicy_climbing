# 🔥 SPICY — 스파이시 클라이밍 온라인 암장

빨간 불꽃이와 함께 벽을 오르는 온라인 클라이밍장입니다.
퇴근하고 몸이 무거운 날, 매운맛 벽 앞에서 잠깐 손끝을 데워요.

## 할 수 있는 것
- **입장**: 닉네임과 내 불꽃 색을 고르고 암장에 들어가기
- **문제 고르기**: 노랑 V0 · 초록 V1 · 파랑 V2 · 빨강 V4 · 보라 V5 · 검정 V6
- **오르기**: 반짝이는 홀드를 순서대로 탭(또는 `Space`/`↑`) → TOP 홀드를 잡으면 완등 🔥
- **펌핑 게이지**: 벽에 매달려 있으면 차오르고, 100%가 되면 매트로 추락. 매트 위에서는 회복
- **초크**(`C`): 펌핑 15% 감소, 3.5초 쿨타임 / **내려오기**(`↓`)
- **단골들**: 하바네로·청양이·떡볶이가 매트에서 수다 떨고, 직접 문제에 붙고, 완등하면 박수쳐줘요
- **실시간 접속**: 같은 링크로 들어온 사람들이 벽에 함께 보여요. 움직임·말풍선·완등이 실시간으로 공유되고, 상단에 접속자 수가 떠요
- **방 나누기**: 주소 뒤에 `?room=친구들` 처럼 붙이면 그 방 사람끼리만 만나요
- **오픈 페스티벌 스탬프 투어**: 6개 문제를 모두 완등하면 페스티벌 완주 배지 🏆 + 실시간 완등 피드
- **🎵 배경음악**: 브라우저에서 즉석으로 만드는 로파이 BGM (음원 파일 없음, 저작권 걱정 없음)
- **한마디**: 말풍선으로 인사 / **내 기록**: 문제별 완등 횟수와 최근 완등 (브라우저에 저장)

## 실행
빌드 없이 정적 파일만으로 동작합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

### GitHub Pages로 배포
1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch` → 브랜치 선택, 폴더 `/ (root)` → **Save**
3. 1~2분 뒤 `https://gyoonus.github.io/spicy_climbing/` 에서 열림

## 실시간 접속은 어떻게 되나요?
서버 없이 공개 MQTT 브로커(`broker.emqx.io`, 실패 시 `broker.hivemq.com`)를 WebSocket으로 써요.
위치·닉네임·말풍선만 주고받고, 기록은 각자 브라우저에만 저장돼요.
공개 브로커라 같은 토픽을 아는 누구나 볼 수 있는 데모용 방식이에요 — 개인정보는 말풍선에 쓰지 마세요.
연결이 안 되면 상단에 `혼자 모드`로 표시되고, 혼자서도 모든 기능이 동작해요.
테스트용으로 `?broker=ws://localhost:8883` 처럼 다른 브로커를 지정할 수 있어요.
