# 🔥 SPICY — 스파이시 클라이밍 온라인 암장

빨간 불꽃이와 함께 벽을 오르는 온라인 클라이밍장입니다.
퇴근하고 몸이 무거운 날, 매운맛 벽 앞에서 잠깐 손끝을 데워요.

## 할 수 있는 것
- **입장**: 닉네임과 내 불꽃 색을 고르고 암장에 들어가기
- **문제 고르기**: 노랑 V0 · 초록 V1 · 파랑 V2 · 빨강 V4 · 보라 V5 · 검정 V6
- **오르기**: 반짝이는 홀드를 순서대로 탭(또는 `Space`/`↑`) → TOP 홀드를 잡으면 완등 🔥
- **펌핑 게이지**: 벽에 매달려 있으면 차오르고, 100%가 되면 매트로 추락. 매트 위에서는 회복
- **초크**(`C`): 펌핑 15% 감소, 3.5초 쿨타임 / **내려오기**(`↓`)
- **단골들**: 하바네로·청양이·떡볶이가 매트에서 수다 떨고, 직접 문제에 붙고, 완등하면 박수쳐줘요
- **한마디**: 말풍선으로 인사 / **내 기록**: 문제별 완등 횟수와 최근 완등 (브라우저에 저장)

## 실행
빌드 없이 정적 파일만으로 동작합니다.

```bash
python3 -m http.server 8000
# http://localhost:8000
```

GitHub Pages, Vercel, Netlify, Cloudflare Pages 등 아무 정적 호스팅에 그대로 올리면 됩니다.

## 파일
- `index.html` — 입구 화면, 암장 UI
- `style.css` — 스타일
- `app.js` — 벽/홀드 SVG 생성, 클라이머, 펌핑·완등 로직, 단골 NPC
- `favicon.svg` — 불꽃이 아이콘
