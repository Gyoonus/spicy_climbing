# 🔥 SPICY — 스파이시 클라이밍 3D 온라인 암장

스파이시 클라이밍 평면도를 그대로 옮긴 3D 암장입니다.
2등신 불꽃이가 되어 섹터를 돌아다니고, 벽에 붙어 오르고, 다이노로 날아보세요.

**▶ https://gyoonus.github.io/spicy_climbing/**

## 🎨 캐릭터 꾸미기 (입장 화면)
- 3D 미리보기를 보면서 고르기: 머리 색 · 머리 모양(불꽃/물방울/별/고양이) · 눈(동글/웃음/반짝/졸림) · 모자·액세서리(헤드밴드/비니/안경/리본/이어폰/헤드셋/악마 뿔/빌런 마스크) · 피부 4톤 · 티셔츠 · 바지 · 볼터치
- 😈 **빌런 유형**: 베타 스프레이어 · 매트 점령자 · 초크 폭격기 · 상탈 빌런 — 이름표가 보라색 😈로 바뀌고, 가끔 알아서 빌런 짓(대사·초크 팡팡·매트에 눕기)을 하면 단골·무호K·웨스트가 반응해요
- 고른 모습은 저장되고, 다른 접속자에게도 똑같이 보여요

## 암장 구성 (실제 평면도 기준)
- **1번 섹터** (노랑) · **2번 섹터** (빨강, 가장 가파른 오버행) · **3번 섹터** (초록) · **4번 섹터** (파랑, 가운데 섬 벽)
- **스프레이월** · **체험벽** · 화장실 · 입구 신발장
- 바닥은 콘크리트, 벽 앞을 따라 두께 30cm 매트가 깔려 있어요 (오버행이 심할수록 넓게)
- 벽 높이: 1·2·3번 5m, 4번 4.2m, 스프레이월 4.4m, 체험벽 3.4m
- **난이도(색)**: 핑크 < 초록 < 노랑 < 빨강 < 남색 < 흰색 < 하늘 < 주황 < 갈색 < 연두 < 검정 (Lv.1~11) — 검정이 제일 어려워요(크림프·슬로퍼 투성이, 게이지 칸 절반, 버튼 시간 짧고 자주, 펌핑 빠름) · 문제 44개 (IFSC처럼 한 문제 8~13홀드, 위·대각·트래버스·사이드 다이노가 섞인 루트, 중간에 ZONE 홀드)
- 🥁 **박자 크럭스**: 1번 갈색 · 2번 연두 · 스프레이 연두 · 3번 흰색 · 3번 검정은 크럭스 홀드(🥁 테이프)를 **박자 게임**으로 잡아요 — 노트가 과녁에 닿을 때 탭(PERFECT/GOOD/MISS), 70% 이상 맞히면 성공. 색이 높을수록 노트 많고 빠르고 판정이 좁아요. 맞는 장비가 있으면 박자 없이 그냥 잡혀요
- 🏆 **ZONE**: 중간의 Z 홀드를 잡으면 ZONE! (문제별 첫 ZONE은 1,000원)

## 🥁 박자 등반 (모든 무브가 박자 게임)
- 홀드를 고르면 그 무브의 박자 노트가 흘러와요. 과녁에 닿을 때 탭(PC는 Space) → 다 처리하면 몸이 옮겨가요
- 노트 수: 저그 2 · 엣지/핀치 3 · 크림프/슬로퍼 4, 데드포인트 +1, 색이 높을수록 +α · 템포 96(핑크)~166(검정) BPM
- 💀 **연속 3번 MISS면 추락** (한 번 맞히면 리셋) · 나쁜 홀드를 잡고 있을수록 MISS 한 번에 체력이 훨씬 많이 까여요
- ↩️ **왔다갔다 금지**: 이미 잡았던 홀드로 돌아가면 힘 빠짐(+15), 두 번째엔 추락
- 🚀 다이노는 멀리(높이) 뛸수록 게이지 바늘이 훨씬 빨라져요

## 🚦 암장 매너 (벽 위 교통사고)
- **선출발자 우선**: 누가 이미 오르고 있으면 기다려요. 기다렸다 붙으면 매너 온도 +0.5

## 🚀 Vercel 배포 (NPC 대화 포함)
1. https://vercel.com 에 **GitHub로 로그인**
2. **Add New → Project** → `spicy_climbing` 저장소 **Import**
3. Framework Preset: **Other**, Build Command / Output Directory는 비워 두기 → **Deploy**
4. 배포 후 **Settings → Environment Variables** 에 추가 → 다시 배포(Deployments → … → Redeploy)
   - `ANTHROPIC_API_KEY` = Claude API 키 (Production, Preview 체크)
   - (선택) `ALLOWED_ORIGINS` = 직접 연결한 도메인이 있으면 `https://내도메인.com` (쉼표로 여러 개). `*.vercel.app`과 `gyoonus.github.io`는 기본 허용
5. **Settings → Git → Production Branch** 를 이 작업 브랜치로 바꾸면 푸시할 때마다 자동 배포
6. 새 주소: **https://spicyclimbing.vercel.app** — 옛 GitHub Pages 주소로 들어오면 Vercel이 열려 있을 때 자동으로 넘어가요(`?room=` 유지). 주소가 다르면 `index.html`의 리다이렉트 주소와 `main.js`의 `NPC_API_REMOTE`를 바꾸면 돼요

## 실시간 접속 방식
서버 없이 공개 MQTT 브로커(`broker.emqx.io`, 실패하면 `broker.hivemq.com`)를 WebSocket으로 써요.
위치, 닉네임, 말풍선만 주고받아요. 공개 브로커라 개인정보는 말풍선에 쓰지 마세요.
연결이 안 되면 `혼자 모드`로 바뀌고 30초마다 다시 시도해요. 테스트할 때는 `?broker=ws://localhost:8883`처럼 브로커를 지정할 수 있어요.
