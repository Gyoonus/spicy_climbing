# 🔥 SPICY — 스파이시 클라이밍 3D 온라인 암장

스파이시 클라이밍 평면도를 그대로 옮긴 3D 암장입니다.
2등신 불꽃이가 되어 섹터를 돌아다니고, 벽에 붙어 오르고, 다이노로 날아보세요.

**▶ https://gyoonus.github.io/spicy_climbing/**

## 암장 구성 (실제 평면도 기준)
- **1번 섹터** (노랑) · **2번 섹터** (빨강, 가장 가파른 오버행) · **3번 섹터** (초록) · **4번 섹터** (파랑, 가운데 섬 벽)
- **스프레이월** · **체험벽** · 화장실 · 입구 신발장
- 바닥은 콘크리트, 벽 앞을 따라 두께 30cm 매트가 깔려 있어요 (오버행이 심할수록 넓게)
- 벽 높이: 1·2·3번 5m, 4번 4.2m, 스프레이월 4.4m, 체험벽 3.4m
- 섹터마다 V0~V6 문제 17개, 다이노 문제 포함

## 🧗 등반 인던 (문제에 붙으면 들어가는 2D 화면)
- S 홀드 근처에서 벽을 잡으면 그 문제의 **2D 등반 화면**으로 들어가요 (자유 등반은 3D 그대로)
- 벽 각도가 표현돼요: 오버행은 위로 갈수록 벽이 넓어 보이고, 오른쪽 위에 옆에서 본 단면(각도·엉덩이 거리·중력)
- **🤖 자동 자세(기본 ON, A)**: 손만 다음 홀드로 끌면 엉덩이와 발이 알아서 편한 자리로 따라와요. 조금 먼 홀드는 몸을 끌어올려서 잡아요
- 직접 하고 싶으면 자동 자세를 끄고 **양손·양발·몸통을 끌어서** 올려요 (모바일은 여러 손가락으로 동시에). 손은 같은 색만, 발은 아무 홀드나(발 자유)
- **🦵 플래깅(F)**: 다리를 반대쪽으로 쭉 뻗는 포즈로 무게중심을 잡아요. 자동 자세면 바니도어 위기 때 알아서 플래깅
- 팔다리 길이보다 먼 홀드는 못 잡아요 → 엉덩이를 옮기거나, 아주 멀면 다이노 게이지(탭/Space)
- **펌핑 = 자세 효율** (손별로 따로)
  - 발에 실리는 무게: 발 2개 > 1개 > 0개, 발이 엉덩이 아래·좋은 홀드일수록, 벽이 가파를수록 적게
  - 🍑 엉덩이 붙이기(H): 오버행에서 팔 부담 감소
  - 팔 쭉 펴기: 엉덩이를 낮추면 효율 ↑, 팔 굽히면 펌핑 ↑
  - 무게중심: 엉덩이가 발 범위를 벗어나면 팔 부담 ↑ · 한쪽 손발만 걸치면 **바니도어** → 반대 발을 뻗어 **플래깅**하면 중심 회복
  - 나쁜 홀드일수록 그 손이 빨리 펌핑, 뗀 손은 털면서 회복, 손을 **초크백으로 끌면** 초크
- 화면에 효율 %와 체크리스트(발 두 개 / 팔 펴기 / 무게중심 / 엉덩이)가 떠요
- 펌핑 100%인 손은 풀리고, 손이 둘 다 떨어지면 추락 · **TOP을 두 손으로 매칭**하면 완등
- 인던에 있는 동안에도 밖(3D)에서는 양손·양발이 실제로 잡은 홀드 위치 그대로 매달린 모습이 실시간으로 보여요 (구경 가능)
- 벽이 높아서 화면이 몸을 따라 위아래로 스크롤돼요

## 클라이밍 규칙 (3D 자유 등반)
- 시작 홀드(S) 근처에서 벽을 잡으면 그 문제로 시작돼요. 같은 색 홀드만 잡을 수 있어요
- 다른 곳에서 잡으면 **자유 등반**이에요. 아무 홀드나 잡을 수 있어요
- 손이 닿는 거리(0.85m) 안에 홀드가 있어야 움직일 수 있어요. 멀면 **다이노**로 날아서 잡아요
- **홀드 종류**: 저그 > 엣지 > 핀치 > 크림프 > 슬로퍼. 나쁜 홀드일수록 펌핑이 빨리 차요
- **다이노 게이지**: 농구 3점슛처럼 Space를 누르면 게이지가 왔다 갔다 해요. 초록 칸에서 떼면 GOOD, 가운데 노란 칸이면 PERFECT. 출발/목표 홀드가 나쁠수록 초록 칸이 좁고 게이지가 빨라져요. 놓치면 힘 부족/너무 셈으로 날아가요
- **더블다이노**: 날아가는 중 TAP 홀드(못 잡는 홀드)를 지날 때 Space를 한 번 더 누르면 다시 튀어 올라요. 2번 섹터 검정 V6는 더블다이노 필수
- **기술** (벽에서 켜고 끄기): 🦵 플래깅 = 펌핑 −40% · ↩️ 인사이드 스텝 = 위로 손 닿는 거리 +0.25m · ↪️ 아웃사이드 스텝 = 옆으로 +0.3m. V3 이상 문제엔 기술이 필요한 먼 홀드가 하나씩 있어요
- 벽에 매달려 있으면 **펌핑**이 차고, 100%가 되면 추락해요. 초크를 바르거나 매트에서 쉬면 회복돼요
- TOP 홀드를 잡으면 완등 🔥
- **초크묻히기**: 등 뒤 초크백에 손을 넣었다가 **쫙! 쫙! 팡!!** 가루 구름과 충격파가 퍼지고 바닥에 초크 자국이 남아요. 근처 사람은 콜록콜록. 펌핑 −18%, 한동안 손이 하얘져요
- **앉아서 쉬기**: 매트에 앉으면 펌핑이 2.5배 빨리 풀려요. 너무 오래 앉아 있으면 단골들이 "너는 맨날 앉아서 쉬냐? 등반은 언제 할래?" 하고 잔소리해요 (세 번 들으면 칭호 '매트 지박령 👻')
- **매달리기**: 팔 쭉 펴고 한 홀드에 대롱대롱. 펌핑이 천천히 차고, 버틴 시간이 최고 기록으로 남아요
- **캠퍼싱**: 발 없이 팔로만 빠르게 올라가요. 펌핑이 2배로 차고, 발을 한 번도 안 쓰고 완등하면 🦍 캠퍼싱 완등

## 🐯 무호K (호랑이 얼굴 스태프 · 친절한 츤데레)
- 툴툴대는 척하지만 다정해요. "…걱정돼서 그런 거 아니고요" 🐯 떨어지면 가끔 챙겨주고, 완등하면 "칭찬은 아니고요" 하면서 칭찬해줘요
- 누가 입장하면 **누구보다 빠르게** 입구로 달려와서 **일일이용 2만원**을 받아요
- 2만원을 내야만 입구 복도에서 안으로 들어갈 수 있어요. 카드 / 현금 / "회원권 있는데요?"(명단엔 없네요 ㅎㅎ) / 몰래 들어가기(바로 걸림)
- 결제는 하루 한 번이에요. 같은 날 다시 오면 "오늘 이미 결제하셨네요~" 하고 들여보내 줘요
- 게임 속 가상 요금이라 실제 결제는 일어나지 않아요
- **한마디** (부드럽게): 4초 넘게 계속 뛰면 4초마다 20% 확률로 쫓아오고, 잡히면 매너 온도 −0.3. 초크 팡팡을 30초 안에 5번 이상 치면 잔소리. 새치기·교통사고엔 20% 확률로 한마디. 한 번 잔소리하면 45초는 조용해요

## 🤠 웨스트 (카우보이 모자, 칭찬 담당)
- 무호K와 정반대예요. **잔소리 0%, 칭찬 100%**
- 완등하면 가끔 달려와서 (내 완등은 처음 깬 문제, V4 이상은 50%. 단골 5%, 다른 접속자 20%. 한 번 찍으면 3분 쉬어요) 휴대폰을 들고 **찰칵! 📸** 웨스트 시점에서 실제 장면을 찍어서 폴라로이드로 보여줘요. 💾 저장 버튼으로 받을 수 있고, 기록창 사진첩에도 모여요
- 벽에 붙어 있으면 근처에서 응원하고, 다이노·양보·캠퍼싱·매달리기 기록을 칭찬해요. 떨어져도 칭찬해요
- 무호K한테 혼나면 "괜찮아요~ 무호가 원래 저래요 🤠" 하고 달래줘요

- 시작 지갑 100,000원(게임 머니). 입장료 2만원이 지갑에서 빠져요 (모자라면 무호K가 외상 달아줌 🐯)
- **완등 보상**: VB/V0 3천 · V1 5천 · V2 8천 · V3 1.2만 · V4 1.8만 · V5 2.5만 · V6 3.5만 — 첫 완등은 ×2
- **암벽화** (마찰 = 발에 실리는 무게, 엣지 = 작은 발홀드, 오버행 = 가파른 벽에서 발): 대여화(무료) · 매드롹 드론 · 레몬아 · 언페럴 플립 · 솔루숀 콤프 · 인싸팅트 VRS · 드라군 · **힘 에디션(최강, 349,000원)**
- **의류**: 바이트 클라이밍 팬츠 — 발 닿는 거리 +8cm, 펌핑 −5%
- 장착한 신발·바지 색이 캐릭터에 보이고 다른 접속자에게도 보여요
- **광고**: 입구 복도 광고판(클릭하면 상점), 가끔 뜨는 광고 카드, 상점의 ‘실제 제품 보기 ↗’ → 힘 에디션(더기어샵) / 바이트 클라이밍 팬츠(스마트스토어) 판매 페이지로 연결
- 게임 속 구매는 가상 머니라 실제 결제는 일어나지 않아요

## 🚦 암장 매너 (벽 위 교통사고)
- **선출발자 우선**: 누가 이미 오르고 있으면 기다려요. 기다렸다 붙으면 매너 온도 +0.5
- **새치기**: 다른 사람이 오르는 근처에 붙으면 매너 온도 −1
- **부딪히면** 💥: 늦게 출발한 쪽이 추락하고 매너 온도 −1.5. 채팅으로 "죄송합니다"라고 하면 +0.7
- **양보**: 겹칠 때 먼저 내려오면 +0.5
- 단골들(하바네로·청양이·떡볶이)도 이 매너를 지켜요

## 그 밖에
- **💬 채팅 로그**: 게임처럼 화면 왼쪽 아래에 글씨만 쌓여요 (닉네임은 각자 불꽃 색). 입장·퇴장·완등 소식도 회색으로 같이 떠요. 머리 위 말풍선은 15초 뒤 사라지고, 대화는 로그에 계속 남아요
- **실시간 접속**: 같은 링크로 들어온 사람끼리 서로 보여요. `?room=크루이름`을 붙이면 그 방 사람끼리만 만나요
- **오픈 페스티벌**: 6개 구역에서 한 문제씩 완등하면 완주 배지 🏆
- **🎵 BGM**: 브라우저에서 즉석으로 만드는 로파이 음악이에요
- 기록과 매너 온도는 브라우저에만 저장돼요

```bash
python3 -m http.server 8000   # http://localhost:8000
```
GitHub Pages: Settings → Pages → Deploy from a branch → 이 브랜치 `/ (root)`

## 실시간 접속 방식
서버 없이 공개 MQTT 브로커(`broker.emqx.io`, 실패하면 `broker.hivemq.com`)를 WebSocket으로 써요.
위치, 닉네임, 말풍선만 주고받아요. 공개 브로커라 개인정보는 말풍선에 쓰지 마세요.
연결이 안 되면 `혼자 모드`로 바뀌고 30초마다 다시 시도해요. 테스트할 때는 `?broker=ws://localhost:8883`처럼 브로커를 지정할 수 있어요.
